# legacy/ — the v3 single-file DiliCards (for reference)

`index.html` is the original **263 KB single-file build** (art inlined as
base64 + PeerJS inlined) that shipped on dilicard.badhon.online before the
React rewrite. Its `test-sim.js` is the old 26-check simulation harness.

The game at the repo root is the new **React + Vite** version — same rules,
same protocol, same clay UI, now componentized and testable.
